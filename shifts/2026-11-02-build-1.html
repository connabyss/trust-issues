The planner Claude
Here's the plan. 1) Build the rule table: every old rule name and its new SA number, read from the new StyleCop's own docs. 2) Read an old Settings.StyleCop file and find the rules it turned off. 3) Write those as .editorconfig lines that turn the same rules off. 4) Move the settings that have a match (private and internal docs, Hungarian prefixes) into stylecop.json. 5) Print a report of everything that didn't move. 6) A command you can run: python -m stylecop_mover Settings.StyleCop One step at a time, a test with each, and the skeptic checks every one.
