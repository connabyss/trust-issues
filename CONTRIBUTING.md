# Contributing

All help is welcome: bug reports, ideas for the robots, typo fixes, art, or code.

## Quick ways to help
- **Found a bug, a broken link, or something hard to read?** Open an issue and say where it was. A screenshot helps.
- **Have an idea for a shift or a new robot?** Open an issue with it.
- **Want to change code?** Fork the repo, make your change on a branch, and open a pull request.

## How the site is built
- `python make_site.py` rebuilds `index.html` (the front page). The page styles live in `robot_team.py`.
- Each shift has its own page in `shifts/`.

## Accessibility
Please keep the site readable for everyone: text and links should pass contrast in light and dark mode, everything should work with a keyboard, and motion should calm down when "reduce motion" is turned on.

Be kind. The robots roast code, never people.
